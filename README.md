 MacroManage POS System

A Custom Bowl Point-of-Sale Application (Java, OOP Capstone)

MacroManage is a console-based POS system that allows customers to fully customize a macro bowl, add drinks, sides, and generate a checkout receipt saved to a file.
The system demonstrates clean Object-Oriented Design principles using Java classes, enums, composition, encapsulation, and separation of concerns.

---
# MacroManage – Project Description

## 🏪 Overview

**MacroManage** is a console-based point-of-sale (POS) application designed to let customers build healthy and customizable **MacroBowls**. Inspired by modern fast-casual restaurants, it allows users to select their bowl size, base, protein, toppings, and sauces while also offering sides and drinks. The system automatically calculates prices, validates orders, and generates professional receipts.

This project was developed as part of the **Year Up / Pluralsight Java Application Development Capstone**. It emphasizes **Object-Oriented Programming (OOP)** principles such as encapsulation, inheritance, and modular design.
